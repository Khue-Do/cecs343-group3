# 0002: File structure
Status: accepted, Class 13\
Decision: We decided to have requirements, process, and verification as separate documents.\
Because: Maintains readability of the repository and keeping them separate makes it easier to update.\
Rejected: combining requirements, process, and verification into one document, because the current layout allows contributors to easily find files.\
Rejected: keeping the files at the root, because having everything grouped under the docs folder keeps the repository organized.\
Costs: Links to the files in README.md, docs/acceptance, docs/decisions, and docs/use-cases would be affected.
